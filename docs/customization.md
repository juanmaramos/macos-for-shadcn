# Customization

Brand-safe variables are `--macos-accent`, `--macos-canvas`, `--macos-content`, `--macos-sidebar-tint`, and `--macos-glass-opacity`. They preserve the intended geometry and state grammar.

Advanced variables include `--macos-control-height`, `--macos-radius-control`, `--macos-radius-surface`, `--macos-shadow-popover`, `--macos-material-blur`, and the motion tokens. Changing them intentionally departs from the measured reference.

Add `data-macos-unstyled` to a component or subtree to return it to the fixture's official Rhea baseline.
